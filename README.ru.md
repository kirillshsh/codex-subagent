# codex-subagent

[English version](README.md)

Скилл для Claude Code, который делает [Codex CLI](https://github.com/openai/codex) субагентом. Разведку кода, которую Claude отдал бы Explore, он отдаёт Codex: где что лежит, как устроено, почему падает, что заденет правка. Токены Codex не попадают в контекст Claude, назад приходит отчёт со ссылками `путь:строка`. По просьбе Codex может и написать бэкенд.

## Что умеет

- **Разведка по умолчанию.** Codex читает код, гоняет тесты и воспроизводит баги, но проект не правит.
- **Тяжёлые баги** (`--heavy`) идут на модель посильнее.
- **Бэкенд** (`--backend`) — только когда ты сам просишь Claude поручить его Codex. Фронтенд остаётся за Claude, если не разрешить (`--allow-frontend`).
- **Песочница.** Codex пишет только в проект и `/tmp`. `--yolo` её выключает.
- **Параллельные запуски.** Когда у аккаунта заняты все параллельные слоты (HTTP 429), обёртка не падает, а ждёт свободный.
- **Продолжение.** `--resume` продолжает тот же диалог с Codex.
- **Проверка дерева после каждого запуска.** Обёртка показывает патчи Codex и всё, что ещё изменилось, и предупреждает, если разведка правила файлы или Codex залез во фронтенд.

## Что нужно

- [Claude Code](https://claude.com/claude-code)
- Codex CLI 0.164 или новее (на старых работает, но изоляция слабее), с входом в аккаунт: `npm install -g @openai/codex`, потом `codex login`
- Python 3.8+
- macOS или Linux

## Установка

Плагином:

```bash
claude plugin marketplace add kirillshsh/codex-subagent
```

```bash
claude plugin install codex-subagent@codex-subagent
```

Или руками: скопируй `plugins/codex-subagent/skills/codex` в `~/.claude/skills/codex`.

## Как пользоваться

Просто попроси Claude: «пусть кодекс найдёт, почему падает тест логина», или напиши `/codex <задача>`. Claude запустит обёртку в фоне, продолжит работать и прочитает отчёт, когда Codex закончит.

Запустить самому:

```bash
python3 ~/.claude/skills/codex/codex_agent.py -C /abs/path/to/project "Где к запросам API применяется лимит?"
```

## Настройки

| Переменная | По умолчанию | Что задаёт |
| --- | --- | --- |
| `CODEX_AGENT_MODEL` | `gpt-6.1-terra` | Модель разведки |
| `CODEX_AGENT_EFFORT` | `xhigh` | Effort разведки |
| `CODEX_AGENT_HEAVY_MODEL` | `gpt-6.1-sol` | Модель для `--heavy` и `--backend` |
| `CODEX_AGENT_HEAVY_EFFORT` | `high` | Effort для `--heavy` и `--backend` |
| `CODEX_AGENT_YOLO` | выкл | `1` убирает песочницу во всех запусках |
| `CODEX_AGENT_HOME` | `~/.claude/codex-agent` | Где хранятся запуски (7 дней) |

Если у аккаунта нет нужной модели, обёртка один раз повторит запуск на модели Codex по умолчанию.

## Безопасность

Codex работает с `approval_policy="never"`: подтверждений не спрашивает. В песочнице по умолчанию он пишет только в проект и `/tmp`, но сеть у него есть. С `--yolo` он может выполнить любую команду на твоей машине — включай только для проектов и машин, которым доверяешь.

Обёртка не читает `~/.codex/config.toml`, поэтому твои MCP-серверы, плагины и хуки в эти запуски не попадают.
